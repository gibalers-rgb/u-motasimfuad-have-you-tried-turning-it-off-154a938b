A program that writes one funny line a hopeless tech support agent says to a desperate customer. It keeps three hand-written candidates, scores each against the judge's own rubric (on-subject, the twist landing, real agent voice, tightness, freshness), and writes the winner to `/output/entry.txt`. The winning line:

> Have you tried turning it off and on again? If that doesn't work, I'll escalate your case to a senior agent — who will ask you the exact same thing, only slower.

(The classic line is the setup, not the punchline: escalation turns out to be the same question again, only slower. The agent is cheerfully useless, and the customer is never the butt of it.)

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (161 characters, one line) and verifies it against the gate (1–199 characters, not only whitespace, single line) before exiting.
